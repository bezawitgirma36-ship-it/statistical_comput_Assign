# Age Calculator Using Python

## Project Description
This project demonstrates a simple Python program that calculates a person's age using their birth year.

## How It Works
The program asks the user to enter their birth year and calculates their age by subtracting the birth year from the current year.

## How to Run the Program
1. Install Python on your computer.
2. Open a terminal in the project folder.
3. Run the following command:

```bash
python sample_data_2.py
```
