# Statistical Computing Assignment

## Project Overview

This repository was created as part of a statistical computing assignment to practice using Git and GitHub for version control. It contains a simple Python program that calculates a person's age using their birth year.

## Project Objectives

- Practice creating and managing a local Git repository.
- Track changes using Git commits.
- Connect a local repository to GitHub.
- Upload and manage project files online.
- Use Markdown to document a project.

## Repository Contents

| File | Description |
|---|---|
| `sample_data_2.py` | Python program that calculates age from a birth year. |
| `sample_data.txt` | Text file containing sample information. |
| `README.md` | Documentation describing the project and its usage. |

## Program Description

The Python program asks the user to enter their birth year and calculates their age by subtracting the birth year from the current year.

**Calculation:**

Age = Current Year − Birth Year

*Note: This calculation uses the birth year only and does not account for whether the person's birthday has occurred in the current year.*

## Requirements

- Python 3
- Git
- A GitHub account

## How to Run the Program

1. Clone or download this repository.
2. Open a terminal in the project folder.
3. Run the Python script using the command:

```bash
python sample_data_2.py
```

4. Enter the requested birth year and view the calculated age.

## Git Commands Practiced

The following Git commands were used to manage the repository:

- `git init` — initializes a local repository.
- `git add` — stages changes for a commit.
- `git commit` — saves a snapshot of the project.
- `git log --oneline` — displays the commit history.
- `git remote add` — connects the local repository to GitHub.
- `git pull` — retrieves and integrates changes from GitHub.
- `git push` — uploads local commits to GitHub.
